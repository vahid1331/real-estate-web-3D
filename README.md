# اندیشه آنلاین | سایت املاک سه‌بعدی

سایت استاتیک املاک با تور اسکرولی ۱۵۰ فریم، سبد خرید، ثبت سفارش و پنل مدیر.

## ساختار
- `index.html` صفحه اصلی
- `css/` استایل و فونت وزیرمتن (base64)
- `js/data.js` عکس‌ها و فریم‌های تور (base64)، `js/app.js` منطق سایت
- `assets/logo.png` لوگو

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages
Settings → Pages → Branch: `main` / root → Save

## پنل مدیر
لینک «ورود مدیر» در فوتر. رمز پیش‌فرض داخل `js/app.js` است، قبل از انتشار تغییرش بدهید.
داده‌ها فقط در مرورگر (localStorage) ذخیره می‌شوند؛ برای سفارش واقعی به بک‌اند نیاز است.
